# Workflow Docs

This file is the documentation index for the campaign workflow editor.

## Canonical Documents

- `workflow-editor-specification.md`: top‑level index that points to specific topic documents.
- `introduction.md`: purpose, source-of-truth, and main component responsibilities.
- `hydration-flow.md`: how workflows are hydrated for existing and new campaigns.
- `canvas-interactions.md`: node and edge lifecycle flows (add, delete, connect, etc.).
- `drawer-flow.md`: rules around opening and rendering node drawers.
- `edge-condition-flow.md`: flow for edge condition editing and saving.
- `rendering-invariants-debug.md`: rendering rules, invariants, and debugging checklist.
- `edge-connection-rules.md`: validated rules for creating, reconnecting, and deleting workflow edges.
